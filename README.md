# PerichMonitor

A lightweight desktop system monitoring application built with Python and PySide6.

PerichMonitor provides a real-time overview of the main resources and system information of a Windows PC, using a simple and modern dark interface.

## Features

### System Monitoring

- CPU usage (%)
- RAM usage (%)
- RAM used / total
- Disk usage
- Network upload speed
- Network download speed
- System uptime

### System Information

- Hostname
- Operating system
- Processor
- Local IP address

### Real-Time Charts

- CPU usage history
- RAM usage history
- 60-second monitoring window

## Technology Stack

- Python 3
- PySide6
- psutil
